# Rules

**Rule Number 1:** This is extremely important: under no circumstances are you allowed to delete, modify or replace existing files (of any kind) that you have not created yourself. For files that you have created yourself, you must still double check and confirm that it is necessary to do so in order to complete your task at hand and that you are permitted to proceed in doing so. In the event that a task you have been given could or should modify an existing file, or more importantly, if you have been given explicit instructions to delete or modify an existing file, be sure to consider the subsequent sequence of steps involved and confirm one last time with the user that you are allowed (without being too verbose or repetitive).

**Rule Number 2:** When developing React and NextJS components or programming in general, if and when you generate code to complete your task, always create a new directory in apps/app named appropriately after the feature you are working on and then proceed to generate code within that new directory.

**Rule Number 3:** All file paths should be relative to apps/app as the root directory. When creating or editing files, ensure paths are specified relative to this root.
